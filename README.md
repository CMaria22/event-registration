# Event Registration Portal

Frontend-only Next.js app where users browse workshops, see availability,
register, cancel, and view their own registrations. There is **no backend**:
every HTTP response (`https://api.example.com/...`) is simulated with
[Mock Service Worker](https://mswjs.io) (MSW).

## Prerequisites

- **Node.js 22.22.2 or newer** (22.x, 24.15+ also works). MSW 3, Vitest 5 and
  jsdom 31 refuse to run on older Node 22 releases. `.nvmrc` pins major 22:
  run `nvm use` (or `fnm use`) in the project folder.
- npm 10+ (ships with Node 22).
- Git.

Check with `node -v`.

## Setup

```bash
git clone <repo-url>
cd event-registration-portal
npm ci
npx playwright install   # browsers for the e2e tests (one-time)
```

Use `npm ci`, not `npm install`: it installs exactly what is in
`package-lock.json`, so every machine and CI get identical versions.

## Run the app

```bash
npm run dev
```

Open <http://localhost:3000/events>. Other pages: `/events/<id>` (for example
`/events/evt-001`) and `/my-registrations`.

## How MSW starts

There are two separate MSW setups sharing the same handlers
(`src/mocks/handlers.ts`):

| Where | Entry point | When it starts |
|---|---|---|
| Browser (`npm run dev`) | `src/mocks/browser.ts` (`setupWorker`) | `src/app/msw-provider.tsx` mounts `msw-init.tsx`, which calls `worker.start()`. The page renders nothing until the worker is ready, so no request escapes before mocking is on. |
| Tests (Vitest) | `src/mocks/server.ts` (`setupServer`) | `vitest.setup.ts` calls `server.listen({ onUnhandledFrame: "error" })` before all tests. |

Details:

- The browser worker only runs when `NODE_ENV === "development"`. In a
  production build (`npm run build && npm start`) MSW is **off** and requests
  go to the real URL, which does not exist. This is intentional.
- The service worker script lives in `public/mockServiceWorker.js`. It is
  generated by `npx msw init public --save` and committed.
- In MSW 3 the option `onUnhandledRequest` was renamed `onUnhandledFrame`.
  With `"error"`, any request without a handler fails the test loudly.

## Mock data

`src/mocks/fixtures.ts`:

- Four events: `evt-001` (5 seats), `evt-002` (unlimited), `evt-003`
  (sold out, 0 seats), `evt-004` (availability unspecified).
- Two demo users: Alice (`user-id-1`) and Bob (`user-id-2`) with different
  initial registrations.

Registrations are kept in memory and reset when the page reloads.

## Switching mock scenarios

Failure scenarios live in `src/mocks/scenarios.ts`:

| Export | Simulates |
|---|---|
| `unauthorizedResponse` | 401 |
| `conflictResponse` | 409 "Already registered" |
| `unprocessableRegistrationResponse` | 422 |
| `serverErrorResponse` | 500 on `GET /events` |
| `slowResponse` | 5 second delay on `GET /events` |
| `invalidJsonResponse` | 200 with a body that fails Zod validation |
| `eventResponse` | a single test event (`evt-test`), used in unit tests |


**In the browser**, set an environment variable and restart the dev server
(Next inlines `NEXT_PUBLIC_*` values at startup):

```bash
NEXT_PUBLIC_MOCK_SCENARIO=serverError npm run dev
```

Valid names: `default` (no override), `serverError`, `slow`, `invalidJson`,
`conflict`, `unauthorized`, `unprocessable`.

## Run the tests

| Command | What it does |
|---|---|
| `npm run lint` | ESLint |
| `npm run typecheck` | `tsc --noEmit` |
| `npm test` | Vitest unit tests, run once |
| `npm run test:e2e` | Playwright on Chromium, Firefox and WebKit |

Useful variants:

```bash
npx vitest run src/app/events                # one folder
npx playwright test --project=chromium       # one browser only
npx playwright test --ui                     # interactive runner
npx playwright show-report                   # open the last HTML report
```

Playwright starts `npm run dev` itself (see `webServer` in
`playwright.config.ts`), so no second terminal is needed. It must be the dev
server, because MSW is disabled in production builds. If a dev server is
already running on port 3000 it is reused.

Run everything before pushing:

```bash
npm run lint && npm run typecheck && npm test && npm run test:e2e
```

## Continuous integration

`.github/workflows/ci.yml` runs on every push to `main` and on every pull
request:

1. **checks**: `npm ci`, lint, typecheck, unit tests.
2. **e2e** (after `checks` passes): Playwright on Chromium only. The HTML
   report is uploaded as an artifact when it fails.

## Troubleshooting

- **`Cannot navigate to invalid URL` in Playwright**: `baseURL` is missing
  from `playwright.config.ts`.
- **`Executable doesn't exist` in Playwright**: run `npx playwright install`.
- **Vitest tries to run Playwright specs**: `vitest.config.ts` must exclude the
  Playwright folder (`tests/**`).
- **Unit test shows `Internal Server Error (500)` from another test**: DOM from
  a previous test was not cleaned up. `cleanup()` must run in `afterEach`.
- **`Unsupported engine` or odd errors on `npm ci`**: your Node is older than
  22.22.2. Run `nvm install 22 && nvm use`.
- **Page stays blank in dev**: the service worker did not start. Check that
  `public/mockServiceWorker.js` exists (`npx msw init public --save`).
